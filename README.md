# Pikakshi Saroha — Personal Portfolio

A single-page, dark-mode technical portfolio built with Next.js, React, Tailwind CSS, Framer Motion, Lucide and React Icons.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Before publishing

1. Add the real resume PDF at `public/resume.pdf`.
2. Replace `[EMAIL TO BE PROVIDED]` in `data/portfolio.ts` with the real email address.
3. Replace `[PROJECT GITHUB LINK]` values with verified repository URLs.
4. Add certificate URLs only when verified.
5. Review project copy against the latest verified project details.
